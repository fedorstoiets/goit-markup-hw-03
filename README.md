# WebStudio — GoIT HTML & CSS Homework #3

Box model and Flexbox layout for the WebStudio page.

Live page: https://fedorstoiets.github.io/goit-markup-hw-03/

Based on Homework #2, with geometry and positioning added without decorative shadows or effects.

## Run locally

Clone the repository and open `index.html` in your browser.

## Project structure

- `index.html`
- `css/main.css`, `css/common.css`, `css/header.css`, `css/hero.css`, `css/features.css`, `css/team.css`, `css/portfolio.css`, `css/footer.css`
- `images/` containing team and portfolio JPGs
